# Chrome extension

Xem [hướng dẫn cài đặt và sử dụng](../README.md).

Nạp chính thư mục này bằng **Load unpacked** tại `chrome://extensions`.
Phiên bản 0.3.0 dùng group **🎙 Dictation** riêng, Native Messaging và hotkey
Ctrl+backtick toàn Windows. Native host phải được đăng ký theo ID extension trên
máy hiện tại. Không có key/profile/credentials được đóng gói trong extension.
